# Tesorería IASD — Análisis Financiero e Informes a la Iglesia (PWA)

Aplicación web progresiva (instalable en celular y PC) diseñada para Tesoreros de la **Iglesia Adventista del Séptimo Día** bajo el estándar **ACMS** y el **Plan de Dádivas Combinadas (60/20/20)**.

## ✨ Características Principales
1. **📝 Carga de Datos Rápida:**
   - Cálculo automático del Plan **60% Presupuesto Local / 20% Campo Local / 20% Misión Mundial**.
   - Separación clara entre **Fondos Remesados a la Asociación** (Diezmos, 40% Mundial/Campo, Proyectos Especiales) y **Fondos Propios de la Iglesia Local** (60% Combinada, Pro-Templo, ASA/Dorcas, Departamentos).
   - Conciliación automática entre **Efectivo en Caja, Cuenta Bancaria y Depósitos en la Asociación**.
2. **📊 Dashboard de Gráficos Modernos y Análisis Inteligente:**
   - **Dona de Distribución Total:** Transparencia sobre adónde va cada dólar/moneda ofrendada.
   - **Gráfico de Flujo Local:** Saldo Inicial, Ingresos, Gastos y Saldo Final.
   - **Gráfico Comparativo por Departamento:** Presupuesto Votado vs. Gasto Real Ejecutado.
   - **Semáforo Presupuestario:** Alertas en verde, amarillo y rojo por cada departamento.
   - **Diagnóstico Inteligente:** Resumen ejecutivo automático sobre superávit/déficit, fidelidad y ejecución.
3. **🖨️ Informe Oficial para los Hermanos (PDF / Proyección / WhatsApp):**
   - Hoja de informe formal con texto bíblico, tablas de ingresos/egresos, ubicación de fondos y firmas para Asamblea Administrativa o Junta Directiva.
   - Envío directo de resumen formateado por **WhatsApp** o exportación a **PDF**.
